# Maths Market

A standalone TappyToe Arcade learning game for Singapore Primary 1–6.

## Current playable prototype

- **Fill a basket:** tap the requested fruit and count out the right amount.
- **Pay the seller:** select coins to make an exact amount.
- **Shop an order:** solve generated addition, subtraction, and multiplication challenges using interactive controls.
- Level-specific values, varied customers and produce, hints, feedback, stars, and saved progress.

## Publish with GitHub Pages

Open Settings → Pages, choose Deploy from a branch, select the main branch and the root folder, then save. Intended URL: https://tappytoe.github.io/maths-market/

To list the game on TappyToe Arcade, add the repository topic tappytoe-game in the About section.

This is an early prototype. Check all learning content against the current Singapore MOE syllabus before presenting it as formal exam preparation.
